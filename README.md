Some geodata-related code I hope can be useful

- [OpenTopoData_API_example](OpenTopoData_API_example.ipynb): example of getting elevation data by bbox from OpenTopoData API with simple 3D-visualization
- [geocoders](geocoders.ipynb): testing open geocoders on Russian cyrillic addresses (tl;dr: quality is not good enough)
- [dust3r_pointmap](dust3r_pointmap.ipynb): [Dust3r](https://github.com/naver/dust3r) usage example - creating point cloud from multiple photos without poses
